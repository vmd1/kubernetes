# Traefik Ingress Controller (`resources/crds-and-operators/traefik/`)

Traefik is a modern HTTP reverse proxy and load balancer designed to deploy microservices easily. In this homelab, it serves as the unified ingress gateway, directing external traffic to internal services and managing SSL/TLS certificates.

This folder contains only the **controller HelmChart**. The Traefik custom resources that build on it (middlewares, TLS options, dashboard, LoadBalancer) live in [infrastructure/traefik/](../../infrastructure/traefik/README.md).

## Design Decisions

- **DaemonSet + Host Network Mode**: Deployed as a `DaemonSet` with `hostNetwork: true` and `dnsPolicy: ClusterFirstWithHostNet`. This exposes ports directly on the host interfaces of edge nodes, removing the need for a secondary NodePort or MetalLB mapping.
- **Global TLS Store**: The default TLS store is tied to the `cluster-wildcard-tls` Secret generated by cert-manager, so any new ingress route automatically gets valid TLS coverage.
- **Cross-Namespace Routing**: Enabled via `--providers.kubernetescrd.allowCrossNamespace=true` so `IngressRoute`s can route to services or bind middlewares (like Authentik SSO) across namespaces.
- **Cloudflare Forwarded Headers & Trusted Proxies**: Official Cloudflare IPv4/IPv6 CIDRs are configured as `forwardedHeaders.trustedIPs` on `web`/`websecure` entrypoints so real client IPs are preserved behind the CDN.
- **HTTP/3 & JSON Logs**: HTTP/3 enabled on `websecure`; access logs emitted in JSON for Promtail/Loki parsing.
- **Entrypoint Redirection**: `web` (80) permanently redirects to `websecure` (443).
- **Server Transport Timeouts**: Dial/response-header timeouts set to 15s and idle connection timeout to 90s.

## Dependencies

- **Cert-Manager**: Relies on the `cluster-wildcard-tls` Secret in the `traefik` namespace for SSL handshakes (see [cert-manager](../cert-manager/README.md)).
- **Authentik**: The `authentik-auth` middleware (used by the dashboard and other routes) is defined in the `authentik` namespace.

## Services & Routers

- **Ports Exposed** (host network):
  - `web` (80, redirects to HTTPS), `websecure` (443 HTTPS, HTTP/3), `matrix-fed` (8448), `dot` (853 DNS over TLS), `traefik` (81, dashboard API).
- **Ingress Routes / middlewares / LoadBalancer**: Defined in [infrastructure/traefik/](../../infrastructure/traefik/README.md).

## Storage

No persistent volume claims are used. Traefik is a stateless reverse-proxy, pulling routing specifications dynamically from Kubernetes API resources (CRDs).
