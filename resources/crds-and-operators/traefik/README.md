# Traefik Ingress Controller (`resources/crds-and-operators/traefik/`)

Traefik is a modern HTTP reverse proxy and load balancer designed to deploy microservices easily. In this homelab, it serves as the unified ingress gateway, directing external traffic to internal services and managing SSL/TLS certificates.

This folder contains only the **controller HelmChart**. The Traefik custom resources that build on it (middlewares, TLS options, dashboard, LoadBalancer) live in [infrastructure/traefik/](../../infrastructure/traefik/README.md).

## Design Decisions

- **DaemonSet + Host Network Mode**: Deployed as a `DaemonSet` with `hostNetwork: true` and `dnsPolicy: ClusterFirstWithHostNet`. This exposes ports directly on the host interfaces of edge nodes, removing the need for a secondary NodePort or MetalLB mapping.
- **Global TLS Store**: The default TLS store is tied to the `cluster-wildcard-tls` Secret generated by cert-manager, so any new ingress route automatically gets valid TLS coverage.
- **Cross-Namespace Routing**: Enabled via `--providers.kubernetescrd.allowCrossNamespace=true` so `IngressRoute`s can route to services or bind middlewares (like the oauth2-proxy SSO middleware) across namespaces.
- **Cloudflare Forwarded Headers & Trusted Proxies**: Official Cloudflare IPv4/IPv6 CIDRs are configured as `forwardedHeaders.trustedIPs` on `web`/`websecure` entrypoints so real client IPs are preserved behind the CDN.
- **HTTP/3 & JSON Logs**: HTTP/3 enabled on `websecure`; access logs emitted in JSON for Promtail/Loki parsing.
- **Entrypoint Redirection**: `web` (80) permanently redirects to `websecure` (443).
- **GeoIP Database & Country Plugin**: the DaemonSet mounts the node's `/var/lib/geoip` (written by the [geoip-updater](../geoip-updater/README.md)) read-only at `/geoip`, and a second inline plugin, `vmd1geo` (`mmdb.go` reader + `plugin.go` middleware), looks up the country of non-Cloudflare clients from `GeoLite2-Country.mmdb`. Its Cloudflare range list is a third copy of the `trustedIPs` list: keep them in sync. The middleware object is in [infrastructure/traefik](../../infrastructure/traefik/README.md).
- **Trace Plugin**: the `vmd1trace` local plugin (`CF-IPCountry` is trusted only from Cloudflare peers; its built-in Cloudflare range list must be kept in sync with the `trustedIPs` lists above) (text for curl, HTML for browsers using the shared vmd1 stylesheet from [vmd1/error-pages](https://github.com/vmd1/error-pages), JSON via `?format=json`; the Edge section has an inline-SVG dotted world map (land path and country centroids generated from Natural Earth, region coordinates in `regionPos`, add a new region there when a node zone is added); the CSS is embedded in the Go source, so keep both in sync; tested under Yaegi, whose tuple assignments in `switch` cases misbehave) (`experimental.localPlugins`, `inlinePlugin` ConfigMap, Go source embedded in the HelmChart values) backs `/.vmd1/trace`; the `NODE_NAME` env var (downward API) feeds `node-name`. The route and middleware live in [infrastructure/traefik/](../../infrastructure/traefik/README.md).
- **Country on Every Request & in the Logs**: the `websecure` entrypoint runs `traefik-geo-country` before `traefik-error-pages` (both in [infrastructure/traefik](../../infrastructure/traefik/README.md), which must be applied first), so every route sees a trustworthy `CF-IPCountry` (Cloudflare's value, or a GeoLite2-Country lookup for direct clients; `XX` when unknown) and `X-Vmd1-Geo-Source`. Both headers are kept in the JSON access log as `request_CF-IPCountry` and `request_X-Vmd1-Geo-Source` (to be verified after rollout; in Loki roughly `{namespace="traefik", container_name="traefik"} | json | request_CF_IPCountry="RU"`).
- **Entrypoint Limits & Error Pages**: `websecure` has `http.maxHeaderBytes=65536` (default 1 MiB), `http2.maxConcurrentStreams=100` (default 250) and the entrypoint-level middleware `traefik-error-pages@kubernetescrd` (defined in [infrastructure/traefik](../../infrastructure/traefik/README.md); that folder must be applied before this argument rolls out). Read/idle timeouts keep Traefik's defaults (60s read, 180s idle, no write timeout).
- **Server Transport Timeouts**: Dial/response-header timeouts set to 15s and idle connection timeout to 90s.

## Dependencies

- **Cert-Manager**: Relies on the `cluster-wildcard-tls` Secret in the `traefik` namespace for SSL handshakes (see [cert-manager](../cert-manager/README.md)).
- **oauth2-proxy**: The `oauth2-proxy-kmnet-uk` middleware (used by the dashboard and other routes) is defined in the `oauth2-proxy` namespace.

## Services & Routers

- **Ports Exposed** (host network):
  - `web` (80, redirects to HTTPS), `websecure` (443 HTTPS, HTTP/3), `matrix-fed` (8448), `dot` (853 DNS over TLS), `traefik` (81, dashboard API).
- **Ingress Routes / middlewares / LoadBalancer**: Defined in [infrastructure/traefik/](../../infrastructure/traefik/README.md).

## Storage

No persistent volume claims are used. Traefik is a stateless reverse-proxy, pulling routing specifications dynamically from Kubernetes API resources (CRDs).
